Review outline:

1. Significance and novelty

The manuscript reports zero-field quantum anomalous Hall (QAH) states at moiré filling ν = 1 in twisted monolayer-rhombohedral N-layer graphene, with quantized ρxy = h/Ne² for N = 3, 4, 5 (devices D1, D2, D3). It also reports two electrically controlled effects: switching the sign of C = ±3 near ν = 3 in a (1+3) device with filling or displacement field, and a displacement-field-driven transition between C = 3 and C = 4 QAH states in a twisted Bernal bilayer-rhombohedral tetralayer (2+4) device. Systematic high-C QAH states with a layer-number dependence, and a D-driven transition between two nonzero Chern numbers, would be of broad interest. However, the novelty relative to closely related recent work, including the authors' own (refs. 39-41, 54, 55), needs to be stated more sharply. The "design principle" framing currently rests on calculations whose key parameter is chosen to fit each device.

2. Potential reasons for acceptance

- Clean data. Zero-field hysteresis loops with ρxy quantized at h/3e², h/4e² and h/5e² (Fig. 1c) agree with Středa slopes from Landau fans (Figs. 2b, 2f, 4g, 4h). This gives two independent determinations of C for the main states.
- The C = ±3 states of the (1+3) configuration appear in three devices (D1, D6, D7; Extended Data Figs. 8, 9). The C = 3 / C = 4 pair of the (2+4) configuration appears in two devices with different twist angles (D4, D5; Extended Data Fig. 7).
- Twist angles agree between full-filling and Brown-Zak determinations for every device (Extended Data Tab. 1).
- Temperature dependence is reported for each main QAH state (Extended Data Fig. 3), with Arrhenius gaps for the (2+4) states (Extended Data Fig. 4).
- A D-tuned transition between two different nonzero Chern numbers at fixed filling, if confirmed, is a new experimental capability.

3. Concerns

A. Must address

1. The "C = N" layer-programming law rests on one device each for N = 4 and N = 5, and the N = 5 device was published before. The central claim is that the layer number N sets C = N for N = 3, 4, 5 (Abstract; Fig. 1c; Discussion: "validates a design principle"). N = 3 is reproduced in D1, D6 and D7. N = 4, however, rests only on D2. N = 5 rests only on D3. The Methods state that D3 "has been systematically studied previously [39]" and was built with a metallic top gate rather than a graphite one, so it is not a new, matched device. For D3, the paper shows only one hysteresis loop (Fig. 1c, right). It gives no Středa fan, no ν-D map, no temperature dependence and no Raman characterization (Extended Data Fig. 1 covers only D1, D2 and D4). Device-to-device spread, and whether C = 4 or 5 appears in every device of a given N, cannot be judged. The authors should:
   - add at least one further (1+4) device, and ideally a new (1+5) device with graphite gates;
   - if that is not possible, show for D3 the Středa analysis, ν-D maps and temperature data in this manuscript;
   - state clearly which results for D3 are new compared with ref. 39.

2. The theory's agreement with experiment is not quantitative, and the key input Δ is tuned per device. The text says the Hartree-Fock (HF) bands "confirm" C = N (Fig. 1b) and that the C = 3 to C = 4 transition "agrees well with band structure calculations" (Fig. 4a). Two problems undercut this.
   - Δ is chosen per device: 9.0, 12.5 and 11.0 meV in Fig. 1b; 11.5 versus 10.0 meV in Fig. 4a. The text calls it "an optimized interlayer potential Δ". The calculated Chern number depends strongly on Δ and θ (Extended Data Fig. 10). For (1+5) in particular, C = 5 occupies only a narrow corner of the (θ, Δ) plane, and much of the map gives smaller C.
   - No mapping from experimental D to Δ is given. So the calculation cannot predict the D values at which the QAH states appear (e.g. −0.540 < D < −0.420 V nm⁻¹ in D1; transition near D ≈ −0.628 V nm⁻¹ in D4).
   - It is also not shown that the sign of Δ used in the calculation matches the experimental sign of D, where QAH appears only for negative D, with electrons polarized away from the moiré interface.
   - For the transition, Fig. 4a assigns C = 3 to the larger Δ (11.5 meV). Experimentally, C = 3 appears at the larger |D| (−0.669 V nm⁻¹). This ordering needs to be shown to follow from a D-to-Δ mapping that includes layer screening, not just asserted.
   - The screening parameters also differ between configurations: d_s = 53 nm for (1+5) and 28 nm for the others, with ε_r = 20, a large value.

   The authors should:
   - supply a D-to-Δ conversion (self-consistent or electrostatic, including interlayer screening) and plot the predicted C(D) against the measured C(D) for D1, D2 and D4/D5;
   - show the sensitivity of the conclusions to ε_r and d_s;
   - state explicitly which spin/valley-polarized HF ground state is assumed, and whether the ordered state is an output of the calculation or an input to it.

   Without this, "design-driven" programming of C (Discussion; Extended Data Fig. 10 as a "prediction") is not supported.

3. The C = 3 to C = 4 transition in the (2+4) system is not shown to be a bulk topological transition rather than coexisting domains, and its reproduction in D5 is incomplete.
   - In D4 (Fig. 4f), the region between the plateaus (−0.641 < D < −0.608 V nm⁻¹) shows ρxy changing smoothly between h/3e² and h/4e². ρxx shows only a modest bump, roughly 0.1 h/e². A clean transition would need a gap to close. Phase separation into C = 3 and C = 4 regions across the Hall bar, for example from twist-angle or D inhomogeneity, would give the same intermediate ρxy.
   - The authors should report D sweeps in both directions across the transition. A first-order transition between differently ordered states should show hysteresis. They should also compare multiple contact pairs or Hall crosses along the bar, which would detect spatial coexistence, and show the activated behaviour of ρxx at the transition point itself. Extended Data Fig. 4a,b shows the two plateaus but not this.
   - In D5, the C = 3 state is shown at B = 1.5 T (Extended Data Fig. 7f, top). Its hysteresis loop (Extended Data Fig. 7c) does not look quantized at h/3e² at zero field. The loop is broad and has intermediate steps, and ρxx is about 0.1 h/e².
   - The statement that the D-driven transition between two zero-field QAH states is reproduced therefore rests on D4 alone. The text should say so, or the authors should provide zero-field quantization of C = 3 in D5.

B. Should address

4. The electrical switching of chirality is shown only at B = 0.1 T, and the mechanism is not calculated.
   - The abstract claims in-situ electrical switching of the sign of C, but every switching sweep (Figs. 3a-d, 3i, 3j) is taken at B = 0.1 T. A finite field biases the valley selection and could be needed for the switching.
   - The authors should show ν- and D-driven switching at B = 0 after field training, and at B = −0.1 T, where the expected inversion would be a useful check.
   - ρxx is not shown in Figs. 3i and 3j, so it is not possible to judge whether the "quantized" ρxy is accompanied by vanishing ρxx throughout the switching ranges.
   - The free-energy diagram in Fig. 3k is a schematic. The explanation from bulk orbital magnetization plus edge contribution (refs. 48, 49) would be much stronger with HF-computed orbital magnetization M(ν, D) for both valleys near ν = 3, showing that M changes sign within the measured windows.
   - The text says opposite Chern numbers "coexist within a single scan direction of D (regions ① and ④)". This reads as a sequential switch during a sweep, not coexistence. The wording should be clarified, along with what is new relative to ref. 32.

5. Rhombohedral stacking in the measured Hall-bar region is not well established.
   - The Raman 2D spectra used to distinguish rhombohedral from Bernal regions in the final stacks are almost indistinguishable for D2 (Extended Data Fig. 1k) and only slightly different for D1 (Extended Data Fig. 1e).
   - Rhombohedral domains can relax to Bernal during transfer, AFM cleaning and etching. Mixed stacking would change both the band topology and the Chern number expected.
   - The authors should show Raman maps of the finished, etched devices overlaid with the Hall-bar outline. Alternatively, or in addition, they should give a transport fingerprint of rhombohedral stacking in each device, such as the D-dependent gap at charge neutrality or the Landau-level sequence at D = 0.
   - D3 has no stacking characterization in this manuscript at all.

6. The quantization quality and the "vanishing ρxx" claims are not quantified, and some statements overstate the data.
   - The text repeatedly says ρxx vanishes and calls the quantization "precise", with "improved robustness compared to other systems".
   - In Fig. 4f, ρxx on the h/4e² plateau is visibly finite, a few hundredths of h/e², i.e. about 1 kΩ. In Extended Data Fig. 4b, ρxx at 0.3 K is about 0.05 h/e² across the range.
   - The authors should tabulate, for each device and state, the deviation of ρxy from h/Ce² (in %), ρxx in Ω at base temperature, and the temperature at which ρxy deviates by more than 1%. Then "improved robustness" should be supported by a quantitative comparison with refs. 15, 31, 32 and 39-41, or removed.
   - The text says quantization persists "up to 3 K" with a Curie temperature of "approximately 8 K". This holds for D1 (Extended Data Fig. 3a-c) but not for D2, where ρxy already deviates at about 1-2 K and the Hall signal vanishes near 5.5 K (Extended Data Fig. 3d-f). It also does not hold for D4, where the Hall signal vanishes near 6 K. The statement should be made state-specific.

7. The "C = 2 Chern insulator at ν = 3/2" is not supported by the Hall resistance.
   - The text says a Chern insulator with C = 2 is "identified" at ν = 3/2 (Extended Data Fig. 5) and attributes it to topological charge order.
   - The zero-field hysteresis at ν = 3/2 (Extended Data Fig. 5c) saturates near 0.3 h/e², close to h/3e², not h/2e² = 0.5 h/e². ρxx is not shown.
   - The only evidence for C = 2 is a Středa line in Extended Data Fig. 5b, which coexists with a C = 3 line.
   - The authors should show ρxx at ν = 3/2, the field at which a C = 2 plateau develops, and whether ρxy reaches h/2e² at any field. Otherwise "C = 2 identified" should be weakened to "a C = 2 Středa feature emanating from ν = 3/2", and the charge-order interpretation presented as a possibility.

8. The activation-gap analysis (Extended Data Fig. 4c,d) has an inconsistent functional form and a narrow fit window.
   - ρxx is fitted to exp(−Δ/2k_BT) but δρxy to exp(−Δ/k_BT). Yet the two give the same Δ (2.09 vs 2.13 meV for C = 3; 1.04 vs 1.03 meV for C = 4). With different prefactors in the exponent, this agreement implies δρxy activates twice as steeply as ρxx. That needs explanation, or one of the formulas is misstated.
   - The fits appear to use only the few points at 1/T < ~0.5 K⁻¹ (T > ~2 K), close to the Curie temperature. Over that range the gap and the magnetization are both temperature-dependent.
   - The authors should state the fit range and number of points and use a consistent definition. They should also note that these gaps (about 1-2 meV, i.e. 12-24 K) are smaller than the energy scales in the HF bands of Fig. 4a.

9. The novelty relative to closely related work needs to be stated explicitly.
   - Refs. 39 (same group, including device D3), 40 and 41 report high-C QAH in twisted rhombohedral graphene. Refs. 54 and 55 (the Note added) report twisted Bernal bilayer-rhombohedral tetralayer graphene and the twisted monolayer-rhombohedral multilayer family.
   - The introduction says how C evolves with N "remains unclear", but does not say what refs. 39-41 already established about C versus N.
   - The authors should add a short, specific comparison: which Chern numbers and configurations were reported before, whether the C = 3 to C = 4 transition or the D-driven chirality switching appears in refs. 54 and 55, and what this work adds.

10. Twist-angle homogeneity and filling calibration are not quantified across the Hall bar.
   - The full-filling and Brown-Zak twist angles agree to 0.01° (Extended Data Tab. 1), but no uncertainty is given and only one contact configuration seems to have been used.
   - Since the C = 3 / C = 4 assignment in the (2+4) system depends sensitively on θ (Extended Data Fig. 10d), the spread of θ and of ν_s between different contact pairs should be reported.
   - The QAH states in Figs. 3 and 4 are located at ν = 2.905, 2.947 and 1.02 rather than at integer fillings. The authors should state whether this offset reflects calibration error in n₀ or the gate capacitances, or genuine physics, for example an extended QAH region as in ref. 31.

C. Minor

11. The field values are inconsistent. The text says "B = ±0.1 T (±90 mT)" for Fig. 2a,e, but 0.1 T and 90 mT are different values. The Fig. 2 caption gives ±0.1 T for panel a and ±90 mT for panel e, and Figs. 2c,d use ±50 mT. Please give the actual value used for each panel.

12. The Fig. 4 text and caption disagree.
   - The text refers to a "red vertical line" in Fig. 4b; the caption says "yellow vertical line".
   - The pink star is at D = −0.603 V nm⁻¹ in the caption but the white line is at −0.602 V nm⁻¹.
   - The text says QAH states are at ν = 1, while the data are at ν = 1.02.

13. In the Extended Data Fig. 4 caption, "Δxx and Δxx" should read "Δxx and Δxy". The δρxy axis is logarithmic but labelled with "0". "Cuire temperature" on p. 4 should be "Curie temperature".

14. Several statements refer to Supplementary Information that was not available for review: Fig. S1 (Brown-Zak), Fig. S2 (D-scan direction dependence), Fig. S5 (suppressed ρxx) and Tab. S1 (residual disorder at ν = 7/3). Key items, especially Fig. S2 for the D-hysteresis, should be summarized in the main text or Extended Data.

15. Devices are compared at different base temperatures: 0.3 K for D1 and D4, 50 mK for D2 and D3 (Fig. 1c). For example, the larger |D| needed for (1+4) is attributed to screening. The temperature for each comparison should be noted, or D1 and D4 data at matched temperature provided where possible.

16. The hysteresis-loop (anti)symmetrization combines up- and down-sweeps (Methods), which forces the loops to be symmetric. Raw Rxy(B) for at least one loop per device would show any asymmetry or exchange-bias-like offset.

17. The explanation that thicker stacks need larger |D| because of "enhanced interlayer screening" is speculative as written. Point to the HF Δ values or a screening estimate.

18. The data availability statement ("upon reasonable request") is weak for a paper making quantization claims. Depositing the source data for the main and Extended Data figures is recommended.

4. Suggestions for improvement

1. Add one more C = 4 device, and if possible a new graphite-gated C = 5 device. Present a summary figure of C versus N across all seven devices, with quantization deviation and ρxx for each.
2. Calibrate D to Δ and overlay the predicted C(D, θ) from Extended Data Fig. 10 on the measured phase boundaries. This turns the "programmable C" claim from qualitative to predictive.
3. Characterize the C = 3 to C = 4 transition more fully: D-sweep hysteresis, several Hall crosses, and the temperature dependence of ρxx at the transition. Demonstrate the transition at zero field in a second device.
4. Show the chirality switching at B = 0, and support the mechanism with calculated orbital magnetization of each valley as a function of ν and D near ν = 3.
